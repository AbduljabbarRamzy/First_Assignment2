# النموذج الرابع - Flutter App

مشروع فلاتر يحتوي على واجهتين كما هو مطلوب في النموذج:

1. **الواجهة الأولى** (`lib/product_card_screen.dart`): بطاقة تعرض تفاصيل منتج (سماعة لاسلكية - 45$).
2. **الواجهة الثانية** (`lib/snackbar_screen.dart`): زر عند الضغط عليه يظهر SnackBar.

## طريقة التشغيل

1. تأكد من تثبيت Flutter SDK على جهازك.
2. فك ضغط الملف ثم افتح مجلد المشروع في الطرفية (Terminal).
3. نفّذ الأوامر التالية:

```bash
flutter pub get
flutter run
```

عند تشغيل التطبيق ستظهر شاشة رئيسية بها زرّان للتنقل بين الواجهتين المطلوبتين في النموذج.

## هيكل المشروع

```
lib/
 ├── main.dart                 # نقطة الدخول والتنقل بين الواجهتين
 ├── product_card_screen.dart  # الواجهة الأولى: بطاقة المنتج
 └── snackbar_screen.dart      # الواجهة الثانية: SnackBar
pubspec.yaml                   # ملف التبعيات
```
